fltk-trayicon

At home in the tray.

Native system tray icons and menus for FLTK applications. Keep a small presence on the desktop, with callbacks in your existing event loop.

fltk-trayicon / usageC++17
#include <fltk_trayicon.h>

Fltk_TrayIcon tray;
tray.icon_svg(icon_markup);
tray.tooltip("My application");
tray.menu({ {"Open settings", 10}, {}, {"Quit", 20} }, 10);
tray.callback([&](Fltk_TrayIcon::Event event, int id) {
    if (event == Fltk_TrayIcon::Event::Menu && id == 10)
        window.show();
});
tray.show();
// Keep the FLTK event loop running to dispatch actions.
